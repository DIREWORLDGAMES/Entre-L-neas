# Instalar Entre Líneas

Abre el sitio publicado de Entre Líneas en un navegador compatible. La instalación requiere una conexión HTTPS y se hace desde el navegador; no hay que descargar un archivo instalador.

## Android

1. Abre el sitio en **Chrome**.
2. Toca el menú **⋮**.
3. Elige **Instalar app** o **Añadir a pantalla de inicio**.
4. Confirma la instalación. Encontrarás Entre Líneas en la pantalla de inicio y en la lista de aplicaciones.

## iPhone o iPad

1. Abre el sitio en **Safari**.
2. Toca **Compartir** (el cuadrado con una flecha hacia arriba).
3. Desplázate y elige **Añadir a pantalla de inicio**.
4. Toca **Añadir**. El ícono aparecerá en la pantalla de inicio.

## Windows

1. Abre el sitio en **Microsoft Edge** o **Google Chrome**.
2. En Edge, abre **Configuración y más (⋯) → Aplicaciones → Instalar este sitio como una aplicación**. En Chrome, selecciona el ícono **Instalar** de la barra de direcciones o abre **⋮ → Guardar y compartir → Instalar página como aplicación**.
3. Confirma. La app aparecerá en el menú Inicio.

## macOS

1. Abre el sitio en **Safari**, **Google Chrome** o **Microsoft Edge**.
2. En Safari, selecciona **Archivo → Añadir al Dock**. En Chrome, usa el ícono **Instalar** de la barra de direcciones o **⋮ → Guardar y compartir → Instalar página como aplicación**. En Edge, abre **Configuración y más (⋯) → Aplicaciones → Instalar este sitio como una aplicación**.
3. Confirma. Entre Líneas estará disponible en el Dock y en la carpeta Aplicaciones.

## Linux

1. Abre el sitio en **Google Chrome** o **Chromium**.
2. Selecciona el ícono **Instalar** de la barra de direcciones o abre **⋮ → Instalar página como aplicación**.
3. Confirma. La app aparecerá en el menú de aplicaciones de tu entorno de escritorio.
